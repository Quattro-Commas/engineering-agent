---
name: product-discovery
description: Convert an idea into user journeys, scope, non-goals, and measurable acceptance criteria.
whenToUse: At the start of a project or before building a major feature.
---

1. Read `AGENTS.md`, `docs/product.md`, and any existing architecture notes.
2. Interview the user or source material for: target users, problem, current workaround, and success signal.
3. Write 1–3 primary user journeys in "As a … I want … so that …" form.
4. Define scope: what is in, what is out, and what is deferred.
5. Draft measurable acceptance criteria for each journey.
6. Identify non-goals explicitly.
7. Record open questions and risks.
8. Save the output to `docs/product.md` or `docs/decisions/` as appropriate.
9. Do not write code until acceptance criteria are agreed.
